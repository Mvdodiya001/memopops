# Blog publishing kit

Copy [article.md](article.md) into the blog editor. Upload the four PNGs at the image positions shown in the article, retain the italic captions, and replace the relative image links with the editor's uploaded image URLs. The first image is also suitable as the cover; keep the full composition rather than a narrow crop. The article mirrors the supplied Spiral Fovea reference's progression: concrete example, essential concepts, visual construction, architecture, measured findings, two limitations, and future directions. The private reference itself is not included.

All figures are original code-generated illustrations on an ivory background, with navy text and muted teal/copper accents. PNGs are 2,520 pixels wide; SVGs retain editable text. Alt text and captions are already in the article. Figures 1–3 are explanatory schematics, not screenshots or measured network behavior. Figure 4 loads the exact checked-in benchmark summary; the generated-case and scaling samples remain distinct.

Regenerate with an existing Python environment containing matplotlib:

```powershell
python docs/blog/proof-carrying-memory/build_figures.py
```

The renderer is an offline publishing utility and introduces no application dependency. The delivered figures used matplotlib 3.10.0. [figure-metadata.json](figure-metadata.json) records the measured source revision, summary checksum, renderer version and figure checksums. Matplotlib may vary embedded timestamps and SVG identifiers across runs; the metadata hashes describe the files generated by that run.

The article intentionally omits detailed latency, concurrency, confidence-interval and weak-baseline comparisons. Complete measurements and their interpretation remain in the linked [report](../../evaluation/benchmark-2026-10-25/REPORT.md). It claims neither universal accuracy nor a new theorem-proving algorithm. Production code and measured artifacts are unchanged by this publishing kit.

The [two-pass verification record](VERIFICATION.md) documents the implementation, data and publishing review. Reproduce its automated checks from the repository root using the project's Python environment:

```powershell
uv run --locked python docs/blog/proof-carrying-memory/verify_article.py
```

This reclassifies the 3,000 saved cases with a separate direct truth-table interpreter, rebuilds the entire summary from the raw observations, replays the article example through the real solver/checker, and checks exported asset provenance and local links. It reads existing measurements without rerunning timings or connecting to FalkorDB.
